05Rationale

Chrome recedes, content leads. One neutral ramp does almost all the work; colour is reserved for meaning — status, due urgency, and the single space accent. The accent only touches the active nav icon, the space tile, primary highlights and charts, so switching space feels like changing rooms without repainting the house.

Two widths of content. Reading surfaces (note editor, report, journal) cap at a measure of 660–760px so lines stay near 70 characters. Data surfaces (tasks, calendar, board) run full-bleed to the page edge with 20px gutters, because scanning columns benefits from width.

Density. 13px UI text, 42px list rows, 36px group headers — closer to Linear than to a card feed. Comfort comes from generous page padding (36–40px) and quiet section gaps, not from padding inside rows. Stats use tabular numerals so columns don't jitter as numbers change.

Keyboard first. Every list has a focused row; every overlay shows its shortcut; mono type marks anything you can type or that is a date.
