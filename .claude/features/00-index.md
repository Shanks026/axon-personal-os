### Backlog scope notes (the starting brief when each feature is planned)

- **15 Attachments and Media**
  - A private Storage bucket `attachments` with paths `{user_id}/{space_id}/{entity_type}/{entity_id}/{filename}`, served only through signed URLs.
  - Images and files in the Tiptap editor (paste or drag-drop upload).
  - File attachments on tasks, and an `attachments` table.
  - **Space images** (the user's request, 2026-09-23): upload an image to use instead of a space's emoji. It goes in the same bucket and becomes a third option beside Emoji in the space dialog.
- **16 Recurring Tasks and Reminders**
  - An `rrule` on tasks, todos and events, with instances generated by `pg_cron` or on completion.
  - `reminders` rows (remind at a given time).
  - In-app notification centre, plus optional browser push.
- **17 AI Assistant** (Claude via a Supabase Edge Function; the API key stays server-side)
  1. Draft a quarterly report from `report_stats` plus completed tasks and journal entries.
  2. Paste text (meeting notes or an email) and extract tasks and todos, with a review step before saving.
  3. "Ask your brain": semantic search over notes, tasks and journal using `pgvector` embeddings, answering with citations.
  4. Summarise a note, and suggest tags.
- **18 Automation and Email Triggers**
  - Inbound email to Inbox: a unique address per user through an inbound email provider and an Edge Function webhook.
  - Scheduled digests: daily agenda and weekly review email.
  - Simple rules, e.g. "when a task is moved to done in THMP, append it to today's journal".
- **19 Data Export and Backup**
  - Full JSON export, and a Markdown export of notes and journal.
  - Import from the JSON export.
  - Settings → Data.
- **20 PWA and Mobile Polish**
  - Installable manifest and offline shell.
  - Mobile navigation (bottom bar or drawer) and touch gestures (swipe to complete).
